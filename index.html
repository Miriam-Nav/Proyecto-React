Moveo: Sistema de Gestión de Alquiler de Videojuegos

Aplicación móvil para la gestión de inventario, clientes y alquileres en tiempo real.

Inicio Tutorial de Uso

Descripción

Moveo es una aplicación desarrollada en React Native y Expo que permite administrar el catálogo de videojuegos, gestionar perfiles de clientes y tramitar alquileres con control de stock automatizado.

Tecnologías utilizadas

  • Frontend: React Native, Expo, TypeScript y React Native Paper.
  • Gestión de estado: TanStack Query, Zustand, React Hook Form y Zod.
  • Backend y persistencia: Supabase (PostgreSQL, autenticación y almacenamiento).

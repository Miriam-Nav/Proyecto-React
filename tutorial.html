Moveo: Guía de Puesta en Marcha y Uso

Pasos para instalar, configurar y ejecutar la aplicación en entorno de desarrollo.

Inicio Tutorial de Uso

Puesta en marcha

  1. Clonar el repositorio: git clone https://github.com/Miriam-Nav/Proyecto-React.git
  2. Instalar las dependencias del proyecto: npm install
  3. Crear el archivo .env a partir de .env.example y añadir las credenciales de Supabase:
    EXPO_PUBLIC_SUPABASE_URL=tu_url
    EXPO_PUBLIC_SUPABASE_ANON_KEY=tu_key
  4. Iniciar el servidor de desarrollo: npx expo start

Flujo de trabajo en la aplicación

  • Autenticación: Iniciar sesión o registrar un nuevo usuario mediante Supabase Auth.
  • Gestión de catálogo: Consultar y dar de alta videojuegos comprobando el stock en tiempo real.
  • Registro de alquileres: Seleccionar cliente y título; el sistema calcula los días y actualiza automáticamente el inventario disponible.
